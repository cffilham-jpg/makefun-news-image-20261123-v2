A one-page world news poster for Monday 23 November 2026: 15 stories across
7 regions, every one dated that Monday. Built for the
[news-image-20261123](https://make.fun/bounty/news-image-20261123) bounty on
make.fun.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Copies `entry.png` (1024x1024, under 1 MiB) to the output directory.
